Automations

Follow-up that never forgets, and knows when to shut up.

Drag a trigger, a delay, a condition and a few actions onto a canvas. The engine handles the part humans get wrong: it stops the moment the seller replies, respects business hours in the contact’s timezone, and caps messages per day.

Triggers
  • New deal, new contact, stage changed
  • Inbound message: SMS, email, Messenger or any
  • Missed call
  • Added to segment, manual enroll
  • Webhook / API from Zapier, forms, any external system
  • Source-based: website form, PPC, referral, purchased list
Timing & conditions
  • Delay in hours or days
  • Send window with timezone
  • Stage is, contact type is
  • Deal score ≥ N
  • Has phone, has email
  • No reply, as a yes/no branch
Actions
  • Send SMS or email from a template, with subject override
  • Create task with title, assignee and due-in-days
  • Add note, change stage
  • Assign owner: teammate, unassigned or round-robin
  • Add to a static segment
  • AI caller

Guardrails live in the engine, not in your memory.

You should not have to remember to add a “stop if they replied” node to every sequence. The engine does it for every automation, every time.

  • Stop on reply: a contact’s reply ends all their active runs across automations
  • One active run per automation and subject, so nobody gets the same sequence twice
  • Daily message cap per contact across all automations
  • Send windows evaluated in the node’s own timezone. 9am in Phoenix is 9am in Phoenix
  • DNC contacts are skipped everywhere, automatically

Leads from anywhere, in the same minute.

A tokenized lead-intake endpoint accepts POSTs from PPC forms, landing pages, lead marketplaces and Zapier. It creates or updates the contact, opens a deal in stage one and fires the new-lead triggers instantly. A second tokenized hook starts any automation from the outside.

  • Duplicates matched by the last ten digits of the phone or by email
  • Source recorded on the deal, so ROI analytics know where it came from
  • Tile list shows Active, Runs, Messages and Last run per automation
